# Yugansh Thacker — Portfolio

AI engineer and builder focused on **AI agents, automation, backend systems, and production-oriented software**.

This repository contains my personal portfolio and selected work. I use projects to learn by building systems end-to-end: architecture, implementation, evaluation, deployment, and failure handling.

## What I Build

- **AI & LLM systems** — agents, structured outputs, retrieval, evaluation, fallbacks, and guardrails
- **Automation & data pipelines** — scheduled ingestion, processing, idempotent workflows, and APIs
- **Backend systems** — Python, FastAPI, Node.js, PostgreSQL, Redis, and distributed-system fundamentals
- **Cloud & deployment** — containerized services, CI/CD, AWS, and production debugging
- **Security-minded engineering** — authentication, rate limiting, validation, observability, and failure testing
